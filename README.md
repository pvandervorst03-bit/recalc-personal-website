# Paul van der Vorst — Recalc Application Site

A static, responsive personal website created for the Recalc Finance Accelerator application.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Unzip this package and upload every file to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

No build step or dependencies are required.

After GitHub finishes publishing, the site will be available at
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
